# Study

## 现实需求
### 理论语言定义
1. 所有语言遵循对象一致性原则（即指代的事物一致即为同类语言，侧重点和情感色采等视为同类语言包的标签），如”结构“、”形式“和”类“（或”系统“）都指代系统和对象，前两者强调框架，后者指代整体

### 前提知识
1. 理论具有工具性和价值性，工具性表现为理论的内容和形式往往具有不变性、严谨性，而价值性表现为该系统具有开创性

### 最初动机
1. 防止重回高中传统的机械记忆理论，使之“学习过程”工具化突出的情况出现
2. 防止理论的两面性的激化，即工具性和价值性的对抗，使”学习过程“价值化突出

### 研究对象（决定性因素）
- 主要
要求：
 - 进行“叙述”和”议论“（主要）的时候，多使用下列的理论结论来论证分析
 - 有关材料需通过B站中通过默认收藏来获取
 - 支持PC端和安卓端
1. 政治
2. 数学
3. 计算机组成
4. 计算机操作系统
5. 计算机网络
- 次要
要求：
- 无须过分理论工具化，只需是经过政治（主要是马原）理论可行后即可
1. 心理学
2. 文学（应用文、议论文和记叙文）

### 现实痛点
1. 传统的教育过分突出课堂知识的感性输出而忽视课堂的理性思考，存在一定程度的机械唯物主义的成分。
2. 由于理论的严谨性，考试主要考察理论的内容和形式的不变性，加之应试下阅卷的痛苦，加重了理论的工具性考察。

### 解决方案
1. 自学（+他学=获取资源）。
2. 输出工具化，输入价值化。
3. 采取主文件夹下为实践区，理论包下为理论区。
